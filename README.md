# Smart Campus Resource Utilization System

A full-stack Smart Campus project built using:

- React.js
- Node.js
- Express.js
- MySQL
- Sequelize
- Tailwind CSS

## Features

- User Authentication
- Role Based Access
- Resource Management
- Booking System
- Booking Cancellation
- Conflict Detection
- Admin Dashboard
- Responsive UI

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js
- Sequelize

Database:
- MySQL

## Run Project

### Backend

cd server
npm install
npm run dev

### Frontend

cd client
npm install
npm run dev
